# managing.software

Homepage and theme based on [oxc-project/website](https://github.com/oxc-project/website),
upstream commit `0e96696318539bd6c74df6f5d4a523927e13fd7a`. The home page is rebranded
for managing.software, with the parser feature adapted for iCloud CLI.

### Contributing

Install [Vite+](https://viteplus.dev) if you don't have it already.

Then run:

```sh
vp install
vp run dev
```
